Praktikum Modul 3 membahas simulasi dan pengendalian robot TurtleBot3 Burger menggunakan Gazebo dan ROS 2. Praktikum ini bertujuan untuk memahami konfigurasi lingkungan simulasi, komunikasi antar-node, serta penerapan sistem kendali robot melalui metode Open Loop dan Closed Loop.

Pada pengujian Open Loop, node square_driver berhasil menjalankan robot mengikuti lintasan berbentuk persegi dan berhenti secara otomatis setelah lintasan selesai. Berdasarkan hasil pengamatan, posisi akhir ground truth Gazebo relatif terhadap posisi awal adalah sekitar (0,047; -0,044), sedangkan posisi odometri /odom sekitar (0,048; -0,045). Hasil tersebut menunjukkan bahwa estimasi posisi odometri mendekati posisi aktual robot dalam simulasi.

Pada pengujian Closed Loop, node obstacle_stop digunakan untuk mengendalikan pergerakan robot berdasarkan data sensor LiDAR melalui topic /scan. Robot bergerak maju ketika tidak terdapat halangan dalam jarak yang telah ditentukan. Ketika objek terdeteksi pada jarak kurang dari nilai stop_distance, robot akan menghentikan gerakan maju dan melakukan rotasi untuk menghindari halangan. Dengan demikian, pergerakan robot dapat menyesuaikan kondisi lingkungan berdasarkan informasi sensor.

Pengujian fail-safe dilakukan dengan mengarahkan subscription sensor LiDAR ke topic yang tidak tersedia, yaitu /scan_mati. Ketika data sensor tidak diterima selama lebih dari nilai scan_timeout, yaitu 0,5 detik, node akan menerbitkan kecepatan nol pada topic /cmd_vel. Mekanisme ini bertujuan memastikan robot berhenti bergerak ketika data sensor tidak tersedia sehingga dapat mencegah pergerakan yang tidak terkendali.

Visualisasi transformasi koordinat dilakukan menggunakan perintah view_frames. Hasil pengamatan menunjukkan bahwa frame odom menjadi parent dari base_footprint, kemudian terhubung ke base_link. Frame base_link selanjutnya terhubung dengan beberapa komponen robot, seperti base_scan, imu_link, dan roda. Selain itu, visualisasi komunikasi antar-node dilakukan menggunakan rqt_graph untuk mengamati hubungan antara node dan topic yang digunakan selama simulasi berlangsung.

Selama praktikum, ditemukan beberapa kendala, seperti service /spawn_entity yang tidak tersedia, topic /odom yang tidak menghasilkan data, serta robot yang tetap bergerak ketika pengujian fail-safe dilakukan. Kendala pada /spawn_entity ditangani dengan memeriksa jalannya Gazebo dan plugin ROS Factory. Permasalahan /odom ditelusuri melalui proses spawn robot dan konfigurasi plugin differential drive. Sementara itu, robot yang tetap bergerak saat pengujian fail-safe disebabkan oleh adanya lebih dari satu node obstacle_stop yang menerbitkan perintah kecepatan. Hal tersebut diatasi dengan menghentikan seluruh node terkait dan menjalankan hanya satu node agar perintah kecepatan tidak saling bertentangan.

Berdasarkan praktikum yang telah dilakukan, simulasi TurtleBot3 Burger menggunakan Gazebo dan ROS 2 dapat digunakan untuk menguji sistem kendali robot. Pengujian Open Loop menunjukkan bahwa robot mampu menjalankan lintasan yang telah ditentukan, sedangkan Closed Loop memungkinkan robot merespons kondisi lingkungan berdasarkan data sensor LiDAR. Pengujian fail-safe juga menunjukkan pentingnya mekanisme penghentian robot ketika data sensor tidak tersedia. Melalui praktikum ini, diperoleh pemahaman mengenai simulasi robot, komunikasi antar-node, transformasi koordinat, serta penerapan sistem kendali dan keselamatan pada robot.
